# tt-comment

Comments are the cheapest distribution on TikTok. A good comment on a big video in your niche is
seen by exactly the audience you want, and it costs one sentence.

## Before you write

1. Read the video first, or the transcript. A comment that could fit any video fits no video.
2. Read `~/.claude/tiktok/voice.md` if it exists. The comment has to sound like the same person as
   the channel, or it reads as a second account.

## The rules

- **Add one true thing.** A mechanism, a number, a correction, a better name for the part. If the
  comment adds nothing, do not write it.
- **Never cold-pitch.** No "check out my page", no "I make videos about this too", no link, no
  follow-for-follow. The first touch is a gift, not an ask.
- **Never flatter.** "Great video" is invisible. The comment that gets liked says something only
  somebody who knows the subject would say.
- **One sentence, maybe two.** A paragraph in someone else's comments is a blog post nobody asked
  for.
- **Never argue with the creator in public.** If they are wrong about the mechanism, say the
  correction plainly and once, with the fact. If they double down, leave it.
- **Never automate the sending.** This skill writes the comment. The user posts it from their own
  account, in their own time. Automated engagement violates TikTok's terms and reads as spam.

## What to hand back

- the comment, in a fenced block, ready to paste
- one line saying what it adds (the mechanism, the number, the correction)
- one line saying why this video, in this niche, is worth the comment

## The gate

Nothing here publishes. This skill writes and you publish. Every output ends in a block the user
copies, and the last line of every run is the question: **ship it, or change it?**
